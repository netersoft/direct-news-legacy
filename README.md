# Direct News (legacy)

News reader built on newsapi.org: headlines, categories, search and saved articles.

This repository holds the native Android app (Java). It is archived and no longer maintained, and the app is no longer published.

## Project

- Application id: `com.neteru.hermod`
- Version in this repository: 1.0.2
- Android Studio project (Gradle), `minSdkVersion` 16

The project targets the Android SDK and Gradle versions of its time and is not expected to build as is with current tools.
